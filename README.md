# شهادة حضور دورة «عند الطوارئ»

موقع ثابت (بدون باك اند) يدخل فيه المشارك رقم جواله بصيغة `05XXXXXXXX`، فتظهر شهادة الحضور باسمه ويقدر يحمّلها PDF أو صورة. كل شيء يشتغل في المتصفح، والموقع مستضاف على GitHub Pages.

## كيف تنحمى البيانات

`data.json` ما فيه أي رقم جوال ولا اسم مكتوب بشكل واضح. كل سجل محفوظ تحت معرّف مشتق من رقم الجوال (PBKDF2-SHA256، 300,000 دورة)، والاسم مشفّر بـ AES-GCM بمفتاح مشتق من نفس الرقم، فالشهادة ما تنفتح إلا بالرقم اللي سُجّلت به. هذا يمنع نسخ القائمة بسهولة، لكنه ما يمنع شخصًا مصرًّا يجرّب كل الأرقام الممكنة.

ردود النموذج الأصلية تبقى في `private/`، والمجلد هذا مستثنى من git.

## تحديث الأسماء

1. صدّر ردود Google Form بصيغة CSV واحفظها في `private/responses.csv`.
2. لتصحيح اسم أو استبعاد رقم، أنشئ `private/overrides.json`:
   ```json
   { "05XXXXXXXX": "الاسم الصحيح", "05YYYYYYYY": null }
   ```
3. ابنِ ملف البيانات (يحتاج Node 20 أو أحدث):
   ```bash
   node tools/build-data.mjs private/responses.csv private/overrides.json
   ```
   السكربت يطبع الأرقام غير الصحيحة، والأرقام اللي لها أكثر من اسم، والأسماء المكتوبة بحروف لاتينية.
4. اعمل commit و push لـ `data.json` فقط.

## التشغيل محليًا

```bash
python -m http.server 8095
```

ثم افتح http://localhost:8095

## الملفات

| الملف | الوصف |

| `assets/certificate.jpg` | الشهادة بدون الاسم (A4 بدقة 288 dpi)، مأخوذة من `شهادة سول.pdf` بعد حذف خانة الاسم |

| `data.json` | السجلات المشفّرة، ويُبنى بـ `tools/build-data.mjs` |
